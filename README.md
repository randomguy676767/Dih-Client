# Dih Client

A clean, fast PvP / quality-of-life client for **Minecraft 1.21.11 (Fabric)**.

## Download

Get the newest jar from **[Releases](../../releases/latest)** and put it in your `mods` folder
(needs [Fabric Loader](https://fabricmc.net/) and [Fabric API](https://modrinth.com/mod/fabric-api) for 1.21.11).
Keep only **one** Dih Client jar in the folder.

Once installed, Dih Client updates itself from this Releases page (Right Shift → Mods → Auto-update).
